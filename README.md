# PC_Builder
🛠️ RIGFORGE — A PC build simulator for the Indian market. Pick CPU, GPU, motherboard, RAM, storage, cooler, PSU &amp; cabinet with real ₹ INR street pricing. Live socket/RAM/PSU compatibility checks, 1440p FPS estimates, one-click budget presets &amp; a build vault. Built with React 19 + Vite 7 + Tailwind v4.
